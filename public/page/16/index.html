https://alvarotrigo.com/fullPage/pricing/

https://alvarotrigo.com/fullPage/ko/#

스크롤을 fullpage로 적용할 때 유용하다. 무료는 v2 버전이고 scrollOverflow 기능에 제한이 있는 등 9유로이니 구매해서 v3 버전을 쓰는 것이 맞다.

CSS Flex 속성이란?

xxxx published on 2021-01-21 included in Css

여기 내용 다 채우기 https://heropy.blog/2018/11/24/css-flexible-box/

Flex 속성이란?

크게 container, items 두가지 영역에 해당한다

Container: display, flex-flow, justify-content

Items: order, flex, align-self 등의 속성이 있다.

Item: flex 값에 대한 해석

flex: 1 -> 모든 공간을 사용 가능하다

flex: 1
<div style="flex:1">flex: 1</div>

화면 전체가 꽉 찬다

flex: 1
flex: 2
<div style="flex:1">flex: 1</div>
<div style="flex:1">flex: 2</div>

화면 전체가 각각 1:1 반반씩 찬다
